# Đo Ánh Sáng Phòng

Trang web ước lượng độ sáng trong phòng bằng camera điện thoại. Mở [trang đã xuất bản](https://ndthinh8796.github.io/light-meter/) trên Safari hoặc Chrome, cho phép dùng camera, rồi chọn việc bạn đang làm: đọc sách, làm việc, thư giãn, hoặc chuẩn bị ngủ.

Kết quả (lux và màu ánh sáng) chỉ là ước tính, dùng để biết phòng đang thiếu sáng, vừa đủ, hay hơi chói.
